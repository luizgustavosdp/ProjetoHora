# ProjetoHora
Este projeto visa melhorar e otimizar a forma de ponto digital nas empresas. No mercado, hoje, há muitos problemas em aplicativos que marcam o ponto, como falta de funcionalidades essenciais, instabilidades constantes e layouts0 confusos. Esse aplicativo visa otimizar o tempo para quemm administra e para quem utiliza no dia a dia, corrigindo todos esses problemas.
